# History

Planning documents from earlier shapes of the project, kept because the
decisions in them are still the reasons for code that exists. None of them
describes the application as it is now.

- `issues/` — the original build broken into eighteen vertical slices. They were
  written for a single-user web app on SQLite with invite tokens; accounts,
  Postgres and the phone app replaced all three.
- `design/` — the accounts-and-Postgres plan, and the teaching-platform and web UI
  designs. The web app and the social features they describe (friends,
  leaderboards, deck sharing) were built and then removed when the project became
  a phone app.

For how the application works today, start at the [README](../../README.md) and
[`docs/spec.md`](../spec.md).
